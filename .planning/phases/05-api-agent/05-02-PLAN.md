Create Hono app with HonoWithConvex type:
```typescript
import { Hono } from "hono";
import { cors } from "hono/cors";
import { HonoWithConvex, HttpRouterWithHono } from "convex-helpers/server/hono";
import type { ActionCtx } from "./_generated/server";

const app: HonoWithConvex<ActionCtx> = new Hono();
```

Add CORS middleware for /api/* routes:
- origin: "*" (can restrict later)
- allowMethods: ["GET", "POST", "PUT", "DELETE", "OPTIONS"]
- allowHeaders: ["Content-Type", "Authorization"]

Add auth middleware for /api/* routes:
1. Extract Authorization header
2. Check "Bearer " prefix, return 401 if missing
3. Extract token, hash it using crypto.subtle.digest
4. Call c.env.runQuery(api.lib.auth.validateToken, { tokenHash })
5. Return 401 if null
6. Store tokenData in context via c.set("apiToken", tokenData)
7. Call next()

Export default new HttpRouterWithHono(app)

Note: Convex actions have access to Web Crypto API for hashing.

Implement these endpoints (all require auth via middleware):

GET /api/v1/drafts
- Check "drafts:read" permission, return 403 if missing
- Query params: status (optional) - "pending", "approved", "rejected", "published"
- Call c.env.runQuery(api.drafts.listAll, { status })
- Return { drafts: [...] }

POST /api/v1/drafts
- Check "drafts:create" permission
- Validate body with zod: { content: z.string().min(1).max(280), metadata: z.object({...}).optional() }
- Call c.env.runMutation(api.drafts.create, { content, authorId: `api:${tokenData.prefix}`, authorName: tokenData.description, metadata })
- Return { id: draftId } with 201 status

GET /api/v1/drafts/:id
- Check "drafts:read" permission
- Get id from c.req.param("id")
- Call c.env.runQuery(api.drafts.getById, { id })
- Return 404 if not found
- Return draft object

POST /api/v1/drafts/:id/approve
- Check "drafts:approve" permission
- Call c.env.runMutation(api.drafts.approve, { id })
- Handle errors (not found, not pending) with 400
- Return { success: true }

POST /api/v1/drafts/:id/reject
- Check "drafts:reject" permission
- Validate body: { reason: z.string().optional() }
- Call c.env.runMutation(api.drafts.reject, { id, reason })
- Return { success: true }

POST /api/v1/drafts/:id/schedule
- Check "drafts:schedule" permission
- Validate body: { scheduledFor: z.number().optional() }
- Call c.env.runMutation(api.drafts.schedule, { id, scheduledFor })
- Return { success: true }

POST /api/v1/drafts/:id/publish
- Check "drafts:publish" permission
- Validate body: { tweetId: z.string() }
- Call c.env.runMutation(api.drafts.markPublished, { id, tweetId })
- Return { success: true }

Import and call registerDraftRoutes(app) in http.ts before the export.

For permission checks, create a helper:
```typescript
function checkPermission(tokenData: TokenData, permission: string, c: Context) {
  if (!tokenData.permissions.includes(permission)) {
    return c.json({ error: "Forbidden" }, 403);
  }
  return null; // permission granted
}
```
