  <name>Task 1: Add token HTTP endpoints</name>
  <files>convex/api/tokens.ts, convex/http.ts</files>
  <action>
Create convex/api/tokens.ts with registerTokenRoutes function:

GET /api/v1/tokens
- Check "tokens:read" permission
- Call c.env.runQuery(api.tokens.listTokens, { createdBy: tokenData.prefix })
- Return { tokens: [...] }

POST /api/v1/tokens
- Check "tokens:create" permission
- Validate body: { description: z.string().min(1).max(100), permissions: z.array(z.string()), expiresAt: z.number().optional() }
- Call c.env.runMutation(api.tokens.createToken, { description, permissions, expiresAt, createdBy: tokenData.prefix })
- Return { token, prefix } with 201 status
- Note: This is the ONLY time the full token is returned

DELETE /api/v1/tokens/:prefix
- Check "tokens:revoke" permission
- Get prefix from c.req.param("prefix")
- Call c.env.runMutation(api.tokens.revokeToken, { prefix })
- Return { success: true }

Import and call registerTokenRoutes(app) in http.ts.
  </action>
  <verify>
Test with curl using a token that has tokens:* permissions:
```bash
# List tokens
curl -H "Authorization: Bearer xpc_..." https://CONVEX_URL/api/v1/tokens

# Create new token
curl -X POST -H "Authorization: Bearer xpc_..." -H "Content-Type: application/json" \
  -d '{"description":"Test Token","permissions":["drafts:read"]}' \
  https://CONVEX_URL/api/v1/tokens

# Revoke token
curl -X DELETE -H "Authorization: Bearer xpc_..." https://CONVEX_URL/api/v1/tokens/xpc_XXXXXXXX
```
  </verify>
