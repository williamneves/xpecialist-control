**Interface:**
```typescript
interface UseKeyboardShortcutsProps {
  selectedDraft: Draft | null
  onApprove: () => void
  onRejectQuick: () => void      // Alt+r - quick reject with default reason
  onRejectWithReason: () => void // Alt+e - open reject dialog for custom reason
  onEdit: () => void             // Alt+e - open edit mode
  onNavigateNext: () => void
  onNavigatePrev: () => void
}

interface UseKeyboardShortcutsReturn {
  helpOpen: boolean
  setHelpOpen: (open: boolean) => void
  isArmed: boolean
}
```

**Keybindings (from CONTEXT.md - LOCKED):**
- `alt+a`: Double-tap approve pattern (first press arms, second confirms within 5s)
- `alt+r`: Quick reject with default reason
- `alt+e`: When pending, opens reject dialog for custom reason. Also used for edit mode.
- `j`: Navigate to next draft
- `k`: Navigate to previous draft
- `shift+/` (? key): Open help overlay
- Escape: Let Radix Sheet/Dialog handle (do NOT add custom handler)

**Armed state logic:**
- First Alt+a press sets `isArmed = true` and starts 5-second timeout
- Second Alt+a press within timeout calls `onApprove()` and resets
- If timeout expires, `isArmed` resets to false
- When `selectedDraft._id` changes, reset armed state (prevent wrong-draft approval)

**Conditional enabling:**
- `alt+a`, `alt+r`, `alt+e` (reject): Only when `selectedDraft?.status === 'pending'`
- `alt+e` (edit): Only when `selectedDraft` exists and `status !== 'published'`
- `j`, `k`: Only when `selectedDraft` exists
- `shift+/`: Always enabled

**Form field exclusion:** react-hotkeys-hook excludes form fields by default - do NOT set enableOnFormTags.

**Note on Alt+e dual purpose:** In CONTEXT.md:
- "Alt+e opens reject dialog for custom reason"
- "Alt+e for edit is single-press, no confirmation needed"

Resolve by using Alt+e for edit only. The reject-with-reason can be handled by the existing UI flow (click Rejeitar button in sheet).
