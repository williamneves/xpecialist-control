Create `src/hooks/useKeyboardShortcuts.ts` with the following:

**Interface:**
```typescript
interface UseKeyboardShortcutsProps {
  selectedDraft: Draft | null
  onApprove: () => void
  onRejectQuick: () => void       // Alt+R (2x) - quick reject with default reason
  onRejectWithReason: () => void  // Alt+Y (while reject-armed) - open dialog for custom reason
  onEdit: () => void              // Alt+E - open edit mode (single press)
  onNavigateNext: () => void
  onNavigatePrev: () => void
}

interface UseKeyboardShortcutsReturn {
  helpOpen: boolean
  setHelpOpen: (open: boolean) => void
  isArmed: boolean        // approve armed state
  isRejectArmed: boolean  // reject armed state
}
```

**Keybindings (from CONTEXT.md - LOCKED):**
- `alt+a`: Double-tap approve pattern (first press arms, second confirms within 5s)
- `alt+r`: Double-tap reject pattern (first press arms, second quick-rejects within 5s)
- `alt+y`: When reject-armed, opens reject dialog for custom reason
- `alt+e`: Edit mode (single press, no confirmation)
- `j`: Navigate to next draft
- `k`: Navigate to previous draft
- `shift+/` (? key): Open help overlay
- Escape: Let Radix Sheet/Dialog handle (do NOT add custom handler)

**Approve armed state logic:**
- First Alt+A press sets `isArmed = true` and starts 5-second timeout
- Second Alt+A press within timeout calls `onApprove()` and resets
- If timeout expires, `isArmed` resets to false
- When `selectedDraft._id` changes, reset armed state

**Reject armed state logic:**
- First Alt+R press sets `isRejectArmed = true` and starts 5-second timeout
- Second Alt+R press within timeout calls `onRejectQuick()` and resets
- Alt+Y press while `isRejectArmed` calls `onRejectWithReason()` and resets
- If timeout expires, `isRejectArmed` resets to false
- When `selectedDraft._id` changes, reset reject armed state

**Important: Both armed states are independent.** If user presses Alt+A then Alt+R:
- Both `isArmed` and `isRejectArmed` can be true simultaneously
- Each has its own timeout
- Completing one action resets only that state

**Conditional enabling:**
- `alt+a`, `alt+r`, `alt+y`: Only when `selectedDraft?.status === 'pending'`
- `alt+e`: Only when `selectedDraft` exists and `status !== 'published'`
- `j`, `k`: Only when `selectedDraft` exists
- `shift+/`: Always enabled

**Form field exclusion:** react-hotkeys-hook excludes form fields by default - do NOT set enableOnFormTags.
