Add new mutation `resubmitDraft` to convex/drafts.ts:

```typescript
export const resubmitDraft = mutation({
  args: {
    id: v.id('drafts'),
    content: v.string(),
  },
  handler: async (ctx, args) => {
    const draft = await ctx.db.get(args.id)
    if (!draft) throw new Error('Draft not found')
    if (draft.status !== 'rejected') {
      throw new Error('Only rejected drafts can be resubmitted')
    }

    await ctx.db.patch(args.id, {
      content: args.content,
      status: 'pending',
      updatedAt: Date.now(),
      rejectionReason: undefined,
    })
    return args.id
  },
})
```

Key points:
- Validates draft exists and is rejected (else throws)
- Updates content to new value
- Resets status to 'pending'
- Clears rejectionReason (set to undefined to remove from document)
- Sets updatedAt timestamp

Place after the existing `reject` mutation for logical grouping.
