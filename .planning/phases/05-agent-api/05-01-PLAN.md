<task type="auto">
  <name>Task 2: Create token utilities and mutations</name>
  <files>convex/lib/apiToken.ts, convex/lib/auth.ts, convex/tokens.ts</files>
  <action>
Create convex/lib/ directory if needed.

convex/lib/apiToken.ts:
- generateApiToken(): returns { token, prefix, hash }
  - Token format: xpc_{nanoid(8)}_{nanoid(32)}
  - Use crypto.subtle.digest("SHA-256", ...) for hashing (available in Convex actions)
  - Return full token (shown once), prefix (for identification), hash (for storage)
- hashToken(token: string): Promise<string>
  - Hash using SHA-256 via Web Crypto API
  - Return hex-encoded hash string

convex/lib/auth.ts:
- validateToken query:
  - Args: { tokenHash: v.string() }
  - Query apiTokens by hash index
  - Return null if not found, revoked (revokedAt set), or expired (expiresAt < now)
  - Return { prefix, description, permissions } if valid
  - Update lastUsedAt timestamp via internal mutation

convex/tokens.ts:
- createToken mutation:
  - Args: { description: v.string(), permissions: v.array(v.string()), expiresAt: v.optional(v.number()), createdBy: v.string() }
  - Generate token using apiToken utilities
  - Insert into apiTokens table
  - Return { token (full, shown once), prefix }

- revokeToken mutation:
  - Args: { prefix: v.string() }
  - Find by prefix, set revokedAt = Date.now()
  - Return success boolean

- listTokens query:
  - Args: { createdBy: v.optional(v.string()) }
  - Return tokens (prefix, description, permissions, createdAt, lastUsedAt, expiresAt, revokedAt) - NOT the hash
  - Filter by createdBy if provided, exclude revoked tokens by default

Note: Import nanoid at top of tokens.ts. Convex supports ES modules with npm packages.

Permission strings to use:
"drafts:read", "drafts:create", "drafts:approve", "drafts:reject", "drafts:schedule", "drafts:publish", "tokens:read", "tokens:create", "tokens:revoke"
  </action>
