# Requirements: Xpecialist Control Dashboard

**Defined:** 2026-02-03
**Core Value:** Efficient high-volume draft review — see pending drafts, make quick decisions, move on

## v1 Requirements

### Review Queue

- [x] **QUEUE-01**: User sees list of pending drafts sorted by creation time (newest first)
- [x] **QUEUE-02**: User can view draft content with character count (280 limit indicator)
- [x] **QUEUE-03**: User can approve draft with confirmation gesture (hold or swipe)
- [x] **QUEUE-04**: User can reject draft with required reason
- [x] **QUEUE-05**: After approve/reject, auto-advance to next pending draft
- [x] **QUEUE-06**: User sees empty state when no pending drafts remain

### Thread Support

- [x] **THRD-01**: Drafts in a thread are grouped together in the queue
- [x] **THRD-02**: User reviews thread as a unit (all tweets visible)
- [x] **THRD-03**: Approving/rejecting a thread applies to all tweets in it

### Editing

- [x] **EDIT-01**: User can edit draft content before approval
- [x] **EDIT-02**: Character count updates live during editing
- [x] **EDIT-03**: User can cancel edit to revert changes

### Scheduling

- [x] **SCHED-01**: User can schedule approved draft for future publish time
- [x] **SCHED-02**: Date/time picker shows user's local timezone
- [x] **SCHED-03**: Scheduled drafts appear in scheduled status view

### Revision Flow

- [x] **REV-01**: Rejected drafts appear in rejected status view
- [x] **REV-02**: User can edit rejected draft content
- [x] **REV-03**: Saving edited rejected draft auto-resubmits to pending

### Status Views

- [x] **STAT-01**: User can filter drafts by status (pending/approved/rejected/scheduled/published)
- [x] **STAT-02**: Each status view shows relevant metadata (rejection reason, scheduled time, etc.)
- [x] **STAT-03**: User can navigate between status views via tabs

### Keyboard Shortcuts

- [x] **KEY-01**: Press Alt+A to approve current draft (double-tap confirmation)
- [x] **KEY-02**: Press Alt+R to open reject dialog
- [x] **KEY-03**: Press j to move to next draft
- [x] **KEY-04**: Press k to move to previous draft
- [x] **KEY-05**: Press Alt+E to open edit mode
- [x] **KEY-06**: Press Escape to close dialogs/cancel actions

### Authentication

- [x] **AUTH-01**: Dashboard requires Clerk authentication
- [x] **AUTH-02**: User identity associated with approve/reject actions
